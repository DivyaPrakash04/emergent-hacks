## 2. Daylight

- Time/weather: ~4:15 PM, early November, fully overcast. Diffuse skylight only —
  **no direct sun** anywhere (no sun patches; umbrella/OJ carton on sill cast only soft
  contact shadows, frames 023–027; window reveals show smooth gradients).
- Sources: window 1 (center z≈1.6) and window 2 (center z≈3.2) on WALL W — tall
  double-hung, ~1.35 m wide, glass from sill 0.78 m to head ~2.45 m, white deep reveals.
  Both admit similar amounts; window 2 feeds the dining corner, window 1 the fridge end.
- A third, weaker daylight source: the glass double doors on WALL F borrow light from the
  lounge behind (its windows face the same lawn) — roughly 1/4 the strength of a window.
- View content blocking sky: a 4-story red-brick building fills most of the upper view
  ~20 m away, lawn below → incoming light is mostly high-angle diffuse, slightly
  directional downward-into-room, with a faint green bounce off the lawn at low angles.
- Color: cool neutral ~6300–6800 K (`#dfe8f0`); lawn bounce tint `#5e6b52` very subtle.
- Intensity: moderate fading-afternoon overcast; sills/white reveals are the brightest
  diffuse surfaces in the scene, but nothing clips except the pendant diffusers.

## 4. Shadows

- Everything is SOFT: overcast key + large-area windows + broad amber shades. No hard edges.
- Contact/occlusion shadows that matter (bake AO or add blob shadows):
  under upper cabinets/cubbies onto backsplash (10–15 cm soft gradient); inside each
  open cubby cell (top/back dark); under counter overhang onto cabinet faces and the
  open knee-space under the sink counter; under microwave and kettle; deep dark slot
  between/behind the two fridges; under radiator covers (dark floor line along WALL W);
  under tables onto floor and banquette seats (charcoal cushions nearly swallow it);
  under banquette seat front; under trash cans; window reveal inner corners.
- Only directional-ish shaping: gentle falloff from windows (objects slightly darker on
  the +X side away from WALL W... i.e., shadow side faces away from the windows).

## 6. three.js recipe

Renderer: `outputColorSpace = SRGBColorSpace`, `toneMapping = ACESFilmicToneMapping`,
`toneMappingExposure = 1.05` (range 1.0–1.15), `useLegacyLights = false`,
`shadowMap.type = PCFSoftShadowMap`. Init `RectAreaLightUniformsLib`.

```js
// 1) Ambient/sky base — overcast dome + floor/lawn bounce
new THREE.HemisphereLight(0xbfccd8, 0x66625a, 0.45);          // sky cool, ground warm-gray
// optional extra flat fill if interior too crushed:
new THREE.AmbientLight(0x3f444c, 0.18);

// 2) Windows (WALL W, x=0 plane) — the daylight key
const win = (z) => { const L = new THREE.RectAreaLight(0xdfe8f0, 7.5, 1.35, 1.65);
  L.position.set(0.02, 1.62, z); L.lookAt(2.5, 1.0, z); return L; };   // faces +X, tilted down
win(1.6); win(3.2);
// Glass doors on WALL F (borrowed lounge light), weaker + slightly warmer-neutral
const doors = new THREE.RectAreaLight(0xd8e0e4, 2.0, 1.6, 2.0);
doors.position.set(4.98, 1.3, 3.3); doors.lookAt(3.0, 1.0, 3.3);

// 3) Soft directional for shadow shaping (NO sun — keep weak and diffuse)
const key = new THREE.DirectionalLight(0xccd9e4, 0.8);
key.position.set(-2.5, 3.5, 2.4); key.target.position.set(2.5, 0.5, 2.4); // from window wall, high
key.castShadow = true; key.shadow.radius = 7; // large soft penumbra; tight ortho frustum to room

// 4) Lit cube pendants P2 & P3 (2700K through amber shade)
const pend = (x, z) => { const p = new THREE.PointLight(0xffb45e, 14, 6.0, 2);
  p.position.set(x, 2.18, z); return p; };
const P2 = pend(2.4, 3.5);           // P2.castShadow = true  <-- the ONE shadow-casting point
const P3 = pend(4.2, 3.4);           // no shadow (perf)
// Shade materials: sides MeshStandardMaterial{ color:0xc9a24b, emissive:0xf5a623,
//   emissiveIntensity:2.5 }, bottom diffuser { emissive:0xfff3dd, emissiveIntensity:4 }.
// P1 at (0.8, 3.5) = same mesh, emissiveIntensity 0, NO light (it is OFF).

// 5) Optional toggles (OFF at capture): under-shelf bar & hood lamp
// bar: RectAreaLight(0xf2ead9, 4, 0.65, 0.04) at (2.7, 1.54, 0.10) facing down (4000K)
// hood: PointLight(0xffd8a8, 5, 1.6, 2) at (3.6, 1.62, 0.35) (2850K)

// 6) Tiny emissives: microwave clock plane emissive 0x39ff6e; faint warm plane behind
// WALL F door glass (lounge spill) emissive 0xffe6b8 * 0.3.
```

- Shadow casters: exactly two — the window DirectionalLight (soft, main) and PointLight P2.
- Bake/fake AO for the contact-shadow list in §4 (aoMap or a subtle SSAO pass);
  blob shadows under tables/banquette if no AO.
- Outside-the-glass backdrop: emissive-ish flat cards only — overcast sky `#cfd4d6`,
  lawn `#5d7a44` with leaf speckle, brick building `#7a4a3d` — lit to read ~0.9 luminance
  through the glass. No sun, no sky gradient needed.
- Target check after tone mapping: pendant diffusers just clip; sills ~0.9; kitchen
  mid-tones ~0.45; under-table ~0.06. Warm/cool split must read clearly across the room
  (amber dining corner vs neutral-cool kitchen/window end).
